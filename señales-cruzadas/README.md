# Señales Cruzadas

## Resumen
- Tipo: Comunicación / Deducción
- Jugadores: 5-8
- Duración: 25-30 minutos
- Intensidad: Media-Alta
- Temática: Transmisión de mensajes mediante sonidos y patrones auditivos
- **Mecánica de interconexión:** Los Transmisores envían mensajes usando sonidos grabados en sus móviles. Los Receptores deben identificar patrones auditivos. El Interferidor mezcla ruido confuso. El Decodificador tiene la clave de sonidos. La información fluye mediante audio: quien reconstruya el mensaje completo primero gana.

## Material
- Móviles con: grabadora de voz, temporizador, notas privadas
- Objetos necesarios: 1 tabla de código sonoro (cada sonido = letra/número), 6 mensajes secretos

## Roles
- **Transmisor Principal**
  - Función: Enviar mensajes mediante secuencias de sonidos grabados
  - Objetivo: Lograr que los Receptores descifren 4 mensajes correctamente
  - Información que posee: Los mensajes que debe transmitir, la tabla de código sonoro
  - Información que oculta: Cuál es el siguiente mensaje
  - Cómo se conecta con los otros roles: Es la fuente de información genuina
  - Acciones especiales: Puede repetir una transmisión 2 veces si hay duda

- **Interferidor Sónico**
  - Función: Mezclar ruidos falsos durante transmisiones para confundir
  - Objetivo: Hacer que se malinterpreten 3 mensajes
  - Información que posee: Puede ver parcialmente los mensajes verdaderos
  - Información que oculta: Su identidad, cuándo interfiere
  - Cómo se conecta con los otros roles: Finge ser Receptor mientras graba y reproduce ruidos confusos
  - Acciones especiales: Puede reproducir grabaciones de ruido 3 veces durante transmisiones

- **Decodificador**
  - Función: Ayudar a interpretar los sonidos usando la tabla de código
  - Objetivo: Asegurar que 4 mensajes se descifren correctamente
  - Información que posee: Tiene la tabla completa de código sonoro (qué sonido = qué letra)
  - Información que oculta: Qué mensaje cree que se está transmitiendo
  - Cómo se conecta con los otros roles: Es el experto de confianza en interpretación
  - Acciones especiales: Puede pedir "confirmación de patrón" al Transmisor 3 veces

- **Receptores (resto)**
  - Función: Escuchar transmisiones y descifrar mensajes
  - Objetivo: Descifrar correctamente los mensajes transmitidos
  - Información que posee: Lo que escuchan, pueden tomar notas de patrones
  - Información que oculta: Sus interpretaciones preliminares
  - Cómo se conecta con los otros roles: Colaboran entre sí para descifrar
  - Acciones especiales: Pueden votar para expulsar al sospechoso de interferir 1 vez

## Cómo se interconectan los jugadores
- **Quién sabe la identidad de quién:** El Transmisor y Decodificador se revelan al inicio. El Interferidor permanece oculto.
- **Quién puede mentir:** El Interferidor miente sobre lo que escuchó. Los Receptores pueden interpretar mal honestamente.
- **Quién debe cooperar:** Transmisor, Decodificador y Receptores cooperan. El Interferidor sabotea.
- **Quién tiene misiones secretas:** El Interferidor debe confundir con ruido falso.
- **Cómo se transmite la información:** Mediante sonidos grabados reproducidos desde móviles. Cada sonido representa una letra según la tabla.
- **Qué rol bloquea o habilita a otros:** El Decodificador habilita comprensión. El Interferidor bloquea claridad auditiva.
- **Qué consecuencias tiene la interacción:** Si 4 mensajes se descifran bien, el equipo gana. Si 3 se confunden, el Interferidor gana.

## Cómo se usa el móvil en el juego
- **Grabadora:** El Transmisor graba secuencias de sonidos (palmadas, golpes, silbidos) que representan letras. El Interferidor graba ruidos confusos.
- **Notas:** Los Receptores anotan los patrones de sonidos que escuchan. El Decodificador tiene la tabla de código.
- **Temporizador:** Cada transmisión tiene 3 minutos para ser descifrada.

## Cómo se juega
1. Se reparten roles vía notas móviles.
2. El Transmisor y Decodificador se revelan.
3. Se distribuye la tabla de código sonoro (ej: 1 palmada = A, 2 palmadas = B, silbido corto = C, etc.).
4. El Transmisor prepara mensaje grabando secuencia de sonidos.
5. El Transmisor reproduce su grabación para todos.
6. Durante o después de la transmisión, el Interferidor puede reproducir su propia grabación con ruidos falsos.
7. Los Receptores anotan los patrones que escucharon.
8. El Decodificador ayuda a traducir usando la tabla.
9. El equipo propone qué mensaje descifró.
10. Se verifica si es correcto.
11. Se repite con nuevos mensajes.

## Fases
### Preparación
- El moderador asigna roles: "Eres Transmisor", "Eres Interferidor", "Eres Decodificador", "Eres Receptor".
- Se crea tabla de código sonoro simple:
  - 1 palmada = A, 2 palmadas = B, 3 palmadas = C
  - 1 golpe en mesa = D, 2 golpes = E, 3 golpes = F
  - Silbido corto = G, silbido largo = H
  - Chasquido = I, etc.
- El Transmisor recibe 6 mensajes cortos (3-5 letras) en su móvil.
- Se distribuye tabla a todos (excepto significados exactos, solo patrones).
- Se inicia temporizador de 28 minutos.

### Acción principal
- Ronda de transmisión (cada una de 7 minutos):
  1. El Transmisor anuncia "Iniciando mensaje [número]".
  2. El Transmisor reproduce su grabación de sonidos.
  3. El Interferidor puede reproducir ruidos confusos durante o después.
  4. Los Receptores toman notas de los patrones escuchados.
  5. El Decodificador consulta su tabla y ayuda a traducir.
  6. El equipo tiene 3 minutos para descifrar.
  7. Proponen el mensaje.
  8. Se verifica si es correcto.

### Conflicto / Sabotaje / Votación
- Si hay confusión extrema, el Transmisor puede usar su poder de repetición (2 usos).
- Los Receptores pueden solicitar al Decodificador confirmación de patrones.
- Si alguien sospecha de interferencia, puede acusar públicamente.
- Se vota para expulsar al sospechoso de ser Interferidor.
- Si la acusación es correcta, el equipo gana inmediatamente.
- Si falla, 1 mensaje automáticamente se cuenta como fallido.

### Final
- **Victoria del Equipo (Transmisor, Decodificador, Receptores):** Descifrar 4 de 6 mensajes correctamente O identificar al Interferidor.
- **Victoria del Interferidor:** Confundir 3 mensajes O llegar al final sin ser descubierto.

## Cómo se gana
- **Equipo:** Descifrar correctamente 4 mensajes mediante patrones de sonido O descubrir al Interferidor.
- **Interferidor:** Hacer fallar 3 descifrados con ruido confuso O sobrevivir sin detección.

## Variantes
- **Para pocos jugadores (5):** 1 Transmisor, 1 Interferidor, 3 Receptores. Sin Decodificador (todos tienen tabla). 3 mensajes necesarios.
- **Para muchos (10+):** 2 Transmisores alternando, 2 Interferidores, 2 Decodificadores. 8 mensajes necesarios.
- **Modo rápido:** 3 mensajes cortos, 15 minutos, código sonoro muy simple (solo 3 tipos de sonido).
- **Modo competitivo:** Puntos individuales por contribuir a descifrados correctos. Primer receptor en proponer mensaje correcto gana bonus.
- **Modo cooperativo puro:** Sin Interferidor. Código sonoro complejo (20 sonidos diferentes), 6 mensajes largos (8-10 letras), 25 minutos.
- **Modo "babel sónico":** 3 Interferidores, transmisiones simultáneas de 2 Transmisores, solo 2 repeticiones permitidas para todo el equipo.
