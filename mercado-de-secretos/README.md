# Mercado de Secretos

## Resumen
- Tipo: Negociación / Intercambio
- Jugadores: 5-8
- Duración: 25-35 minutos
- Intensidad: Alta
- Temática: Compraventa de información clasificada
- **Mecánica de interconexión:** Los Comerciantes intercambian secretos de diferentes valores. El Tasador valida autenticidad. El Falsificador vende información falsa. Los Compradores completan sets de secretos. La información fluye mediante negociaciones privadas: quien reúne el set completo primero obtiene puntos.

## Material
- Móviles con: notas privadas, temporizador, cámara
- Objetos necesarios: 20 tarjetas de secretos (4 categorías de 5 niveles), fichas de valor

## Roles
- **Comerciante Principal**
  - Función: Intermediar intercambios de secretos entre jugadores
  - Objetivo: Facilitar 10 intercambios exitosos y cobrar comisión
  - Información que posee: Todos los secretos disponibles en el mercado
  - Información que oculta: Qué jugador tiene qué secretos
  - Cómo se conecta con los otros roles: Es el centro del mercado, todos deben negociar con él
  - Acciones especiales: Puede vetar 2 intercambios sospechosos

- **Falsificador**
  - Función: Crear y vender secretos falsos como si fueran reales
  - Objetivo: Lograr que 3 jugadores compren sus secretos falsos
  - Información que posee: Conoce el formato de secretos verdaderos
  - Información que oculta: Su identidad, cuáles secretos son falsos
  - Cómo se conecta con los otros roles: Debe fingir ser Comprador legítimo mientras vende falsificaciones
  - Acciones especiales: Puede crear 3 secretos falsos convincentes

- **Tasador**
  - Función: Verificar autenticidad de secretos antes de intercambios
  - Objetivo: Prevenir que secretos falsos circulen
  - Información que posee: Tiene lista maestra de secretos verdaderos
  - Información que oculta: Qué secretos ha validado o rechazado
  - Cómo se conecta con los otros roles: Es el filtro de confianza del mercado
  - Acciones especiales: Puede inspeccionar 5 secretos durante la partida

- **Compradores (resto)**
  - Función: Adquirir secretos para completar sets temáticos
  - Objetivo: Ser el primero en completar un set de 4 secretos de la misma categoría
  - Información que posee: Sus propios secretos, pueden ver ofertas públicas
  - Información que oculta: Qué secretos necesitan para completar sus sets
  - Cómo se conecta con los otros roles: Compiten entre sí, dependen del Comerciante y Tasador
  - Acciones especiales: Pueden denunciar a un sospechoso de falsificación 1 vez

## Cómo se interconectan los jugadores
- **Quién sabe la identidad de quién:** El Comerciante Principal se revela. El Falsificador permanece oculto. El Tasador puede revelarse o mantenerse secreto.
- **Quién puede mentir:** El Falsificador miente sobre sus secretos. Los Compradores pueden bluffear sobre qué necesitan.
- **Quién debe cooperar:** El mercado funciona con cooperación para intercambios. El Falsificador sabotea la confianza.
- **Quién tiene misiones secretas:** El Falsificador debe vender falsificaciones. Cada Comprador tiene un set secreto que necesita.
- **Cómo se transmite la información:** Negociaciones privadas cara a cara. Ofertas públicas verbales. Secretos se muestran en notas móviles.
- **Qué rol bloquea o habilita a otros:** El Comerciante habilita intercambios. El Tasador bloquea falsificaciones. El Falsificador contamina el mercado.
- **Qué consecuencias tiene la interacción:** Si un Comprador completa su set con secretos válidos, gana puntos. Si compra falsificaciones, pierde.

## Cómo se usa el móvil en el juego
- **Notas:** Cada jugador registra sus secretos actuales. El Falsificador crea secretos falsos convincentes. El Tasador tiene la lista maestra.
- **Temporizador:** Cada ronda de negociación dura 5 minutos.
- **Cámara:** Para fotografiar intercambios como prueba de transacción.

## Cómo se juega
1. Se reparten roles y secretos iniciales vía notas móviles (cada jugador empieza con 3 secretos aleatorios).
2. El Comerciante Principal abre el mercado anunciando la primera ronda.
3. Los jugadores tienen 5 minutos para negociar intercambios privadamente.
4. Cualquier intercambio debe pasar por el Comerciante (quien cobra comisión en fichas).
5. Los jugadores pueden solicitar tasación antes de aceptar un secreto.
6. El Tasador revisa y confirma si es auténtico o falso (sin revelar quién lo vendió).
7. Los Compradores intentan completar sets de 4 secretos de la misma categoría.
8. El Falsificador intenta colocar sus falsificaciones como si fueran reales.
9. Se pueden hacer denuncias de falsificación con votación.
10. El primer Comprador en completar un set válido gana.

## Fases
### Preparación
- El moderador asigna roles: "Eres Comerciante Principal", "Eres Falsificador", "Eres Tasador", "Eres Comprador de categoría [X]".
- Cada jugador recibe 3 secretos iniciales aleatorios en sus notas.
- Se distribuyen fichas de valor (10 por jugador).
- El Comerciante recibe la lista completa de 20 secretos.
- El Tasador recibe la lista maestra de secretos verdaderos.
- Se inicia temporizador de 30 minutos.

### Acción principal
- El Comerciante anuncia: "Abierta ronda [número] de negociaciones".
- Los jugadores circulan negociando intercambios de secretos.
- Cada intercambio debe registrarse con el Comerciante (paga 1 ficha de comisión).
- Los jugadores pueden solicitar tasación (cuesta 2 fichas).
- El Falsificador intenta vender sus falsificaciones discretamente.
- Cada ronda dura 5 minutos.

### Conflicto / Sabotaje / Votación
- Si un jugador sospecha de falsificación, puede denunciar públicamente.
- Se vota si se investiga al acusado.
- Si se descubre que vendió falsificaciones, es el Falsificador y pierde.
- Si la acusación es falsa, el denunciante pierde 3 fichas.
- El Tasador puede intervenir mostrando evidencia sin revelar su rol.

### Final
- **Victoria de un Comprador:** Completar un set de 4 secretos válidos de la misma categoría.
- **Victoria del Falsificador:** Vender 3 secretos falsos sin ser descubierto O que termine el tiempo sin que nadie complete un set.
- **Victoria del Comerciante:** Si nadie completa sets pero él facilitó 10+ intercambios.

## Cómo se gana
- **Compradores:** Ser el primero en completar un set de 4 secretos auténticos de la misma categoría.
- **Falsificador:** Vender 3 secretos falsos sin ser descubierto O impedir que alguien complete un set válido.
- **Comerciante:** Facilitar 10 intercambios exitosos (gana si nadie más ganó antes).

## Variantes
- **Para pocos jugadores (5):** 1 Comerciante, 1 Falsificador, 3 Compradores. Sin Tasador. Sets de 3 secretos.
- **Para muchos (10+):** 2 Falsificadores independientes, 2 Tasadores. Sets de 5 secretos.
- **Modo rápido:** Sets de 3 secretos, 20 minutos, sin tasaciones.
- **Modo competitivo:** Puntos por cada secreto correcto. El jugador con más puntos al final gana.
- **Modo cooperativo:** Sin Falsificador. Todos trabajan juntos para completar 5 sets diferentes antes del tiempo.
- **Modo "mercado negro":** 3 Falsificadores, secretos valen el doble, solo 3 tasaciones disponibles para todo el equipo.
